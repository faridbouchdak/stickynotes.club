## Image specification

- 1080 x 1920 px, 9:16, sRGB JPEG.
- Four separate files.
- Keep all words between y=250 and y=1650 px.
- Use at least 64 px body text and strong dark-on-light contrast.
- Repeat the important message in text; do not rely on colour.

## Alt/accessibility note

WhatsApp Status does not provide the same durable alt-text workflow as some feed platforms. Keep each frame's message large, concise and high-contrast, and do not make the image necessary to understand the wording.
